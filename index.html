Importer votre historique YouTube

YouTube ne donne pas accès à l'historique depuis son API, mais vous pouvez l'exporter :

  1. Ouvrez Google Takeout, désélectionnez tout, puis cochez seulement « YouTube et YouTube Music ».
  2. Dans le choix des données YouTube, ne gardez que l'historique.
  3. Dans « Formats multiples », choisissez JSON pour l'historique (le format HTML proposé par défaut ne peut pas être importé).
  4. Créez l'export, téléchargez l'archive .zip et choisissez-la ici telle quelle (ou le fichier watch-history.json qu'elle contient).

Toutes les vidéos regardées sont retirées du fil, et les 500 plus récentes apparaissent dans l'historique. Le fichier reste sur votre appareil. Takeout peut programmer un export tous les deux mois : réimportez-le pour rester à jour.
